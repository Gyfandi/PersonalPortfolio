# Portofolio Personal Kreatif

Website portofolio personal berbasis **HTML5 dan CSS3** untuk memperkenalkan profil, keahlian, dan proyek-proyek web yang pernah dibuat. Dibuat sebagai tugas mata kuliah.

## Deskripsi Singkat

Portofolio ini adalah halaman web satu halaman (*single page*) yang berisi:

1. **Beranda**: perkenalan singkat dan ajakan menjelajahi karya.
2. **Tentang Saya**: profil sebagai mahasiswa Informatika.
3. **Keahlian**: kumpulan bahasa pemrograman, framework, dan kebiasaan kerja.
4. **Proyek**: empat proyek website beserta tangkapan layar dan teknologi yang digunakan.
5. **Pendidikan**: latar belakang pendidikan dan proses belajar.
6. **Kontak**: email dan tautan media sosial.

## Keahlian

- **Web Development**: HTML5, CSS3, JavaScript, PHP, PHP Native, Laravel
- **Programming**: Java, Python, Git, TypeScript, TSX, React Native
- **Creative Thinking**: Problem solving, UI basics

## Teknologi yang Dipakai pada Portofolio Ini

- HTML5 dengan struktur semantik (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3 pada file terpisah (`style.css`), memakai Grid, Flexbox, variabel CSS, dan media query
- Tanpa framework CSS seperti Bootstrap atau Tailwind
- Responsif untuk desktop, tablet, dan ponsel

## Cara Menjalankan

1. Clone repository ini:
   ```bash
   git clone https://github.com/Gyfandi/PersonalPortfolio.git
   ```
2. Masuk ke folder proyek.
3. Buka file `index.html` di browser (Chrome, Firefox, atau Edge).

Tidak perlu instalasi tambahan karena website ini hanya memakai HTML dan CSS.
